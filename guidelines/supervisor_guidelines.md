## Overall the structure of the thesis

## Chapter 1: Introduction

## It should include:

- Problem statement

- Motivation

- Objectives of your thesis

- Main contribution(s)

## Chapter 2: State-of-the-art

- Write a summary of the paper with main findings. Include dataset information such as number of samples, groups/labels, methods, and best results.

- Make a table to summarize the works reviewed in the state-of-the-art

## Chapter 3: Theoretical background

- Concepts relevant for the problem

- Machine learning/deep learning methods relevant for the thesis

- Evaluation metrics

- Figures to explain concepts, architectures, etc&.

## Chapter 4: Data description

- Number of samples; how it was capture; if open-source, then put the link.

- Create table summarizing the metadata if apply.

- Make figures or plots to either show the data or the data distribution.

## Chapter 5: Experiment and Results

- Include the conclusions of each experiment

- If the tables are too dense, use bar plots so it is easier to see the results

## Chapter 6: Summary

## Some recommendations:

- The font type of the figures and tables must be the same as the text. The font size should be approximately the same as the text.

- Make a table to summarize the works reviewed in the state-of-the-art.

- Make sure that the main content of the thesis is no more than 50-60 pages. But it can be longer if there are many figures and appendices.
