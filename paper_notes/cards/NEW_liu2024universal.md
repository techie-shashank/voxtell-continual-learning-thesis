## Facts (from the paper, each with location: Sec./p./Table/Fig.)
- Task / problem: one 3D CT model for 25 organs and 6 tumour types trained on partially labelled public datasets, which can be extended to new classes without access to earlier data (Abstract; Sec. 1; Sec. 3.1).
- Data (Sec. 4.1.1; Table 1): 14 public datasets, 3,410 CT volumes "used for AI development", split 2,100 training / 1,310 validation; external test: 3D-IRCADb (20), TotalSegmentator (1,024), private JHH (5,038, 21 organs), private UCSF (11 patients with liver metastases). Abstract says 6,173 test volumes from four external datasets, Sec. 1 says 6,162 from three; the paper does not reconcile the two.
- Method (two sentences): a fixed CLIP text embedding of the template "A computerized tomography of a [CLS]" for each class is concatenated with globally pooled image features and fed to a class-specific MLP (language-driven parameter generator, LPG) that outputs the weights of a class-specific head of three 1×1×1 convolutions (8, 8, 1 channels) applied to the decoder features, giving one sigmoid mask per class (Sec. 3.2.2–3.2.3, Eq. 1–2). Backbone Swin UNETR; text embeddings are precomputed because the class dictionary is fixed (Sec. 4.1.2).
- How new classes are added (Sec. 3.3, p. 5): for each new class an additional MLP is added to the LPG, producing a new class-specific head; old classes are supervised on the new data by the previous model's predictions as soft pseudo labels, new classes by ground truth (Eq. 5). No distillation beyond pseudo labelling (Sec. 5.1.3). Whether the backbone is frozen during the continual steps is not stated; Sec. 3.2.4 describes updating "the entire framework" for integrated training.
- Setting: class-incremental, no earlier data, class names known; text is a fixed per-class template, not a free-text prompt. Not few-shot. Evaluated as continual learning in "Experiment II" (Sec. 5) with two benchmarks: tumour extension (BTCV 13 organs, step 1 → LiTS liver tumour, step 2) and body extension on private JHH (7 abdominal organs → 3 gastrointestinal → 4 cardiovascular, 3 steps). Baselines LwF, ILT, PLOP with the same Swin UNETR backbone (Sec. 5.1.2); 100 epochs, lr 1e−4, batch 2 (Sec. 5.1.3).
- Forgetting measure: none as a separate metric; the paper reports DSC per class (Table 10) or per body-part group (Table 11) after each step, so forgetting is visible only as the DSC drop between steps.
- Results, continual (Table 10, p. 13): after step 2, organ mean DSC 0.817 (step 1: 0.860), liver tumour 0.466, mean over 14 classes 0.792, vs LwF 0.770 / 0.456 / 0.748, ILT 0.786 / 0.335 / 0.754, PLOP 0.799 / 0.362 / 0.768 (baselines' step-1 organ mean 0.828). Body extension (Table 11, p. 14): after step 3, organs 0.787, gastro 0.692, cardiac 0.636 vs best baseline 0.777 (PLOP), 0.486 (LwF), 0.484 (ILT); one-hot instead of CLIP embedding gives 0.777 / 0.665 / 0.452. No variance or number of runs reported for Experiment II.
- Results, integrated training: BTCV five-fold mean DSC 86.13 vs Multi-Talent 85.75 (Table 4); first place on six MSD CT tasks (Table 3); best prompt template "A computerized tomography of a [CLS]" with mean DSC 76.11 vs one-hot 70.42 (Table 7). Cost of a new head: 9.44×10^−4 GFLOPs vs 466.08 GFLOPs for a new Swin UNETR decoder as in Ji et al. (Sec. 5.4).
- Limitations stated by the authors (Sec. 6, p. 14): mainly abdominal CT; CLIP embeddings not optimised for the medical domain; unlabelled regions not exploited.

## Where it fits in Ch. 2 (suggestion)
- Sec. "Concept-Level Text Conditioning" (related_work.tex l. 32) currently cites the ICCV version [Liu_2023] with "14 CT datasets comprising 3,410 training scans"; per this paper 3,410 is training plus validation (2,100 / 1,310), and the continual-learning experiments are only in this journal version. It also belongs in "Segmentation Networks" (l. 85) next to Zhang et al., whose class-specific heads and pseudo-label scheme it shares; it supports the closed-set point made there.

## Relevance (NOT from the paper)
The closest prior continual-learning study for a text-conditioned 3D segmentation model, but the text is a fixed class-name template, new classes get new MLP/heads, and forgetting is only read off per-step DSC. It does not contradict the gap claim if the claim keeps "free-text promptable" and a shared parameter set; it should be named explicitly when stating the gap, since an examiner may cite it.
