## Facts (from the paper, each with location: Sec./p./Table/Fig.)
- Task / problem: "open-domain continual learning" (ODCL) of CLIP for image classification: a stream of datasets from different domains with overlapping or correlated classes; the model must keep both the knowledge learned on earlier datasets and CLIP's zero-shot ability on unseen domains (Abstract; Sec. 1, p. 1–2; Sec. 3.1).
- Data (Sec. 4.1, p. 6): the 11-dataset benchmark of ZSCL (Aircraft, Caltech101, CIFAR100, DTD, EuroSAT, Flowers, Food, MNIST, OxfordPet, StanfordCars, SUN397), one dataset per task, 1,176 distinct classes after all 11 tasks. Two task orders from ZSCL: Order I alphabetical (main results), Order II a fixed random order (Suppl. C, Tables 8–10). Full training sets; epochs per dataset from 1 (Food, SUN397) to 63 (Flowers) (Suppl. A).
- Method (two sentences): with both CLIP-ViT-B/16 encoders frozen, each task learns one task prompt token (length 1, input layer only) prepended to the image tokens, with an attention mask that stops earlier prompts attending to later ones, and a LoRA module (rank 5) in the text encoder that refines the class text embeddings, trained with cross-entropy plus an L2 regression term and energy-score-based negative labels from earlier tasks (Sec. 3.2–3.4, Eq. 1–8; Sec. 4.1). The refined class embeddings are stored in a class vocabulary keyed by class name and updated by momentum (α = 0.1); the LoRA module is discarded after each task, so no exemplars, no reference dataset and no distillation are used (Sec. 3.3, Eq. 2). Trainable parameters 0.13 M vs 149.62 M for ZSCL (Table 6).
- Setting: two inference settings in the paper's own terms: ODCL-TIL (task ID given; predict within the task's class set) and ODCL-CIL (task ID not given; predict over the union of all seen classes) (Sec. 3.1, p. 3). In ODCL-CIL all t learned task prompts are applied and the maximum logit is taken for classes in several tasks; classes not in the vocabulary use CLIP's original embeddings (Sec. 3.5). Not few-shot.
- Evaluation (Sec. 4.1, p. 6), all accuracies in %, following ZSCL: **Avg** = mean accuracy over all 11 datasets at all time steps (seen and not yet seen); **Last** = mean accuracy over all datasets after the last task; **Transfer** = mean accuracy on each dataset at the time steps before it is learned (zero-shot on unseen domains; reported for ODCL-TIL only, Table 3). The paper adds **Forgetting**, defined as the mean accuracy on each dataset from the step it is learned to the last step, so higher is better (it is not a drop measure). Baselines: zero-shot CLIP, ZSCL, and the closed-domain methods CODA-Prompt and LAE with per-class linear classifiers (no Avg/Transfer for these) (Sec. 4.1, p. 6–7).
- Best result (Order I, mean over 11 datasets): ODCL-CIL Last 79.95 vs ZSCL 77.38, CLIP 57.81, LAE 62.14, CODA-Prompt 62.00; Avg 73.78 vs ZSCL 71.56; Forgetting 81.74 vs ZSCL 79.80 (Table 1, p. 6). ODCL-TIL Last 84.70 vs ZSCL 83.71; Avg 76.41 vs ZSCL 75.32 (Table 2, p. 7). Transfer 69.04 vs ZSCL 67.86 and CLIP 69.27, i.e. a drop of 0.23 vs 1.41 points for ZSCL (Table 3; Sec. 4.2). Order II, ODCL-CIL Last 79.43 vs ZSCL 76.22 (Table 8; read from the text extraction with the same row offset as Table 1, verified against the PDF for Table 1 only). Cost on Aircraft: one epoch 37.38 s vs 256.18 s, 26.8 GB vs 43.3 GB GPU memory for ZSCL (Table 6).
- Ablation: vocabulary momentum update raises ODCL-CIL Last by 8.48 points over the LoRA-only baseline (Table 4; Sec. 4.3). LoRA beats Adapter and Prefix in the text encoder (Table 5).
- Limitations stated by the authors: none stated (no limitations section; Sec. 5 is a summary). The paper notes ZSCL's Last on Caltech101 falls below CLIP zero-shot (Sec. 4.2, p. 7), which concerns ZSCL, not CoLeCLIP.

## Check of the author's notes
- related_work.tex:62 "CoLeCLIP instead shares part of the adaptation across tasks" → correct: the class vocabulary is shared, the task prompts and per-task LoRA modules are not (Sec. 3.2–3.3).
- related_work.tex:62 "it learns visual prompts per task in the frozen image encoder" → correct; one prompt token per task at the input layer (Sec. 3.4; Sec. 4.1).
- related_work.tex:62 "but maintains a single vocabulary of class text representations across all tasks, updated through a momentum rule as new classes appear" → partly correct: the vocabulary is shared and momentum-updated (Eq. 2), but the update runs at every training iteration for the classes of the current task (also classes seen before), while new classes are first inserted with CLIP's original text embedding (Sec. 3.3). The sentence also omits the per-task LoRA module in the text encoder that produces the refined embeddings. Better: "updated by momentum from embeddings refined by a per-task LoRA module in the text encoder".
- related_work.tex:184 (table) "Eleven MTIL datasets | Task prompts, shared class vocabulary | Final 79.95 % (ZSCL 77.38 %)" → numbers correct, label imprecise: 79.95 and 77.38 are the **Last** metric (mean accuracy over all 11 datasets after the final task) in the **ODCL-CIL** setting (no task ID), Order I (Table 1, p. 6). "Final" is not the paper's term. Better: "Last 79.95 % (ZSCL 77.38 %), ODCL-CIL". The paper does not call the benchmark "MTIL" (it calls it a benchmark of 11 datasets from ZSCL, Sec. 4.1); "MTIL" is ZSCL's name, so the cell is acceptable only if MTIL is defined via ZSCL.
- introduction.tex: no sentence about CoLeCLIP found.

## Relevance (NOT from the paper)
Closest VLM analogue to the thesis's single-parameter-set setting with a shared text side: it shows that keeping the frozen encoders and adapting only lightweight per-task inputs can beat full fine-tuning with distillation (ZSCL) on both Last and Transfer, at 0.13 M trained parameters, though on classification and full data, not few-shot segmentation.
