## Facts (from the paper, each with location: Sec./p./Table/Fig.)
- Task / problem: exemplar-free domain-incremental image classification: classes stay fixed while domains change from session to session, no exemplars of old domains stored (Abstract; Sec. 1, p. 1–2; Sec. 3.1).
- Data (Sec. 4, p. 6): CDDB-Hard (continual deepfake detection, real/fake), 5 domains in the order GauGAN, BigGAN, WildDeepfake, WhichFaceReal, SAN, about 27,000 images; CORe50, 50 classes from 11 domains, 8 domains (120,000 images) for training and the 3 remaining, unseen domains as test set; DomainNet, 345 classes, about 600,000 images, 6 domains, setup as in CaSSLe. Out-of-domain test: FaceForensic++, Glow, StarGAN (Sec. 4, Table 7).
- Method (two sentences): the pretrained transformer (ViT-B/16 for S-iPrompts, CLIP for S-liPrompts) is frozen, and for each domain an independent prompt set is learned (image prompts prepended to the image tokens; for S-liPrompts also a learnable text context prompt in front of the class-name tokens) together with a domain classifier, trained with plain cross-entropy (Sec. 3.1–3.3, Fig. 2). At inference, K-Means centroids (K = 5) stored per domain in the prompt-free feature space of the frozen image encoder are searched by 1-NN to pick the domain, whose prompts and classifier are then used (Sec. 3.1; Sec. 4 Ablations, p. 8–9; Fig. 5). No exemplar memory and no regulariser; memory overhead +0.03 % per domain for S-liPrompts (Sec. 4 Overheads). Default lengths: image prompt 10, language prompt 16 (Fig. 5 caption).
- Setting: domain-incremental learning (DIL), task index not given at inference (Sec. 1, p. 1); a TIL variant with domain index given is reported for comparison (Table 6). Not few-shot. Classification only.
- Evaluation: CDDB-Hard: average (forward) detection accuracy and average forgetting degree (as in CDDB); CORe50 and DomainNet: average (forward) classification accuracy (Sec. 4, p. 6). Upper bound: supervised fine-tuning on i.i.d. data of all tasks (Table 1–3 captions). Baselines: EWC, LwF, ER, GDumb, BiC, DER++, Co2L, iCaRL, LUCIR, LRCIL, DyTox, L2P, CaSSLe; exemplar-free competitors are EWC, LwF, L2P, CaSSLe (Sec. 4 Methods).
- Best result (S-liPrompts, exemplar-free, average accuracy in %): CDDB-Hard 88.65, forgetting −0.69, vs best exemplar-free competitor L2P 61.28 and best exemplar-based DyTox (50/class) 86.21; upper bound 91.91 (Table 1, p. 7). CORe50 89.06 ± 0.86 vs L2P 78.33 (exemplar-free) and 81.07 (50/class); upper bound 93.19 (Table 2). DomainNet 67.78 vs DyTox (50/class) 62.94, exemplar-free best Supervised-Contrastive-CaSSLe 50.9; above its own upper bound 64.08 (Table 3). Summary claim: about 30 % average relative improvement over best exemplar-free methods, about 6 % over exemplar-based ones (Abstract; Sec. 4 Results). Inference 11.84 ms vs 9.37 ms for plain CLIP on one RTX-3090 (p. 7).
- Domain identification: 1-NN accuracy on CDDB-Hard 0.80 (CLIP features) and 0.82 (ViT) (Table 5); with random domain selection, S-liPrompts still reaches 80.12 (Table 4); the authors conclude the method is "not fundamentally influenced" by identification accuracy (Sec. 4, p. 8). TIL vs DIL task-agnostic AA 92.51 vs 91.54 (Table 6).
- Limitations stated by the authors (Sec. 5, p. 10): results are not appealing when applied directly to class-incremental learning, because CIL is more sensitive to incorrect domain/task identification. No other limitation stated.

## Check of the author's notes
- related_work.tex:62 "S-Prompts learns an independent set of visual and textual prompts for each domain and selects them at inference by assigning the test image to the nearest of the feature centroids stored per domain" → correct for S-liPrompts (Sec. 3.1, 3.3; Fig. 2). S-iPrompts uses image prompts only; centroids are K-Means centres (K = 5) of the frozen encoder's features.

The dependence is real but, on DIL, weaker than the sentence suggests; the CIL limitation below is the paper's own evidence for it.

## Relevance (NOT from the paper)
The clearest example of full parameter isolation with a frozen vision–language backbone and a learned selection step; the analogue of task-specific LoRA in this thesis, which replaces the centroid search by task identity supplied at inference.
