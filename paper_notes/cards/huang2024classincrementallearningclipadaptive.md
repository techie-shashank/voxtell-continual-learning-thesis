## Facts (from the paper, each with location: Sec./p./Table/Fig.)
- Task / problem: exemplar-free class-incremental image classification with CLIP; old classes that are semantically close to new ones are forgotten more, and the paper targets this non-uniform forgetting (Abstract; Sec. 1, pp. 2–3; Fig. 1).
- Data (Sec. 5.1, p. 8): CIFAR100 (100 classes, 500 train / 100 test images per class, 32 × 32), ImageNet100 (100-class subset of ImageNet1K, class list in Suppl. A), ImageNet-R (200 classes, split following prior work), CUB200 (11,788 images, 200 classes), ImageNet1K. Splits written as B (base classes) / Inc (classes per step), e.g. B0 Inc10, B50 Inc5, B100 Inc20 (Tables 1–3). The text says "three datasets" but lists five. Task order: results are the mean over several shuffles of the class order (Sec. 5.1; Table 1 caption); number of shuffles not stated.
- Method (two sentences): CLIP ViT-B/16 image and text encoders are frozen and only one linear adapter on the image features is trained with cross-entropy, using features of old classes sampled from per-class Gaussians (stored mean and covariance, with covariance shrinkage), plus a hinge loss that pushes sampled features of an old class away from the text feature of a new class whose normalised text feature lies within distance α = 0.65 (Sec. 3 "Feature Generation"; Sec. 4.1–4.2, Eq. 3–6; Sec. 5.1). After each task the new and previous adapter weights are fused: W_old is decomposed by SVD into an orthonormal basis B (shared knowledge) and coefficients R, W_new is projected onto B, and the coefficients are mixed with an element-wise soft mask from their normalised change (Eq. 7–11), so the parameter count does not grow with tasks (Sec. 4.3; Sec. 1).
- Setting: class-incremental learning, no task identity at inference, disjoint class sets, no old data (Sec. 3); exemplar-free (Tables 1–3, "Exemplar" column); no few-shot setting. Training: Adam, 15 epochs, learning rate 0.001, decayed ×0.1 at epochs 4 and 10; about 2000 sampled features per epoch as simulated replay; 20 extra features per selected class per iteration; one RTX 3090 (Sec. 5.1, p. 9).
- Evaluation (Sec. 5.1, p. 8): "Avg" = mean of the accuracies A_t after each task (A_t = accuracy on tasks 1..t after task t); "Last" = accuracy after the final task. Baselines: L2P++, DualPrompt, CODA, SLCA, ADAM-Adapter, PROOF (uses exemplars), Continual-CLIP (zero-shot CLIP), all with the same OpenAI CLIP weights (Sec. 5.1). Supplement: conventional methods (Coil, DER, iCaRL, FOSTER) and RanPAC (Tables 9, 10, 14).
- Best result: ImageNet1K B0 Inc100 Avg 81.73 / Last 72.58 vs best competitor DualPrompt 79.39 / 69.79 and Continual-CLIP 72.96 / 64.44 (Table 4, p. 11). CUB200 B0 Inc20 Last 76.34 vs PROOF 75.53 (Avg 83.04 vs 83.11, PROOF slightly higher) (Table 4). CIFAR100 B0 Inc10 86.19 / 79.04 vs PROOF 84.88 / 76.29 (Table 1, p. 9). ImageNet100 B0 Inc10 87.51 / 80.23 (Table 2); Last at least 1.58 % above all others on ImageNet100 (Sec. 5.2). ImageNet-R B0 Inc20 85.58 / 80.28 (Table 3). Not best everywhere: on CIFAR100 B50 Inc10 SLCA has Last 79.92 vs 79.36 (Table 1), and RanPAC is higher on CIFAR100 (87.15 / 80.96 vs 86.19 / 79.04; Suppl. Table 14). Ablation (ImageNet100 B0 Inc10 Last): adapter + Gaussian sampling 73.80, + hinge 76.04, + fusion without decomposition 79.28, full 80.23 (Table 5).
- Limitations stated by the authors (Sec. 6, p. 14): the threshold α is chosen by hand; future work on an adaptive threshold, more efficient fusion, and the mutual influence of text and image. Also stated: a too-large threshold selects dissimilar pairs and adds computation (Sec. 5.3, Fig. 6).

## Check of the author's notes
- related_work.tex:54 "RAPF keeps both encoders frozen and trains only a single linear adapter on the visual output" → correct (Sec. 1, p. 3; Sec. 4.1; Eq. 1).
- related_work.tex:54 "It uses the text encoder to identify old and new classes with neighbouring textual representations, separates them through a hinge loss on pseudo-features sampled from stored class distributions" → correct (Sec. 4.2, Eq. 3–5; the stored distributions are per-class Gaussians, Sec. 3). Precise: the hinge loss is applied to the old class of each selected pair only.
- related_work.tex:54 "and fuses the adapter weights of successive tasks through a shared decomposition rather than replacing them" → correct (Sec. 4.3, Eq. 7–11); the basis is the SVD of the previous adapter weights.
- related_work.tex:54 "Where all parameters are trainable, as in ZSCL and GIFT, ...; RAPF instead bounds it by confining training to a single linear layer, which places it between regularisation and the parameter-efficient methods considered next" → author's interpretation, not from the paper. The paper itself places RAPF among methods that keep the pre-trained model unchanged and add parameters (Sec. 2.1), and it also relies on Gaussian feature replay, which the paragraph (titled regularisation) does not mention. An examiner may question the grouping; consider naming the replay component.

## Relevance (NOT from the paper)
Shows that, with frozen encoders, text-feature similarity between class names can predict which old classes a new class will interfere with; the analogue in this thesis would be overlap between the text prompts of SKM-TEA structures. The SVD-based fusion is a weight-merging alternative to keeping separate adapters.
