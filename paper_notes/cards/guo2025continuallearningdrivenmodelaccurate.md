## Facts (from the paper, each with location: Sec./p./Table/Fig.)
- Task / problem: one CT model that segments 235 whole-body anatomies learned from many partially labelled datasets, able to add new anatomies without forgetting earlier ones; framed against dataset-specific nnU-Nets, multi-dataset models and SAM-style foundation models (Abstract; Sec. 1, p. 4–5).
- Data (Sec. 2, p. 6–8; Suppl. Table S1): 36 internal 3D CT datasets, 13,952 scans: 20 public (4,855 scans; 3,904 train / 951 test; 162 structures) and 16 private (9,097 scans; 7,278 train / 1,819 test; 125 structures, 73 not in the public data). 235 anatomy types: 193 organs, 33 lymph node stations, 9 lesions. External test: 7 datasets, 1,979 scans, 43 anatomy types, from institutions not providing training data for that body part. Comparative subset: five public datasets (TotalSegmentator V2, StructSeg19, SegTHOR, FLARE22, KiTS21), 1,471 scans, 137 anatomy types (Sec. 2.1, p. 10).
- Method (two sentences): a CNN general encoder is trained first (e.g. on TotalSegmentator V2) and then frozen; one lightweight decoder per anatomy or group of anatomies is added and trained, with Lottery-Ticket-Hypothesis pruning of each decoder and feature-level supporting between related decoders (Sec. 1, p. 5; Sec. 4, p. 22–23; Fig. 2). In the continual configuration datasets arrive one at a time: new decoders are added for unseen anatomies, existing decoders are fine-tuned with EMA for anatomies seen before, all others stay frozen, and outputs of all decoders are merged with body-part-regression bounding (Sec. 2, p. 8; Suppl. A2, p. 42–43; Sec. 4.1).
- Setting: no text conditioning (fixed output set of decoders); scenario "continual semantic segmentation" (CSS, dataset-sequential) and a "universal segmentation" (partial-label, simultaneous) configuration; no task identity at inference, all decoders run and predictions are merged (Sec. 4, Eq. 1–3; p. 22); no few-shot setting. Four task orders (O1–O4) of the five public datasets to test order sensitivity (Suppl. A2, p. 42; Fig. 4).
- Evaluation: DSC (%) and ASD (mm); model size (MB) (Tables 1–4). Baselines: ensemble of 36 (or 5) nnU-Nets trained per dataset (called upper bound in the CSS comparison), MultiTalent, SAT-Pro, VISTA3D, BiomedParse; CSS methods MiB, PLOP, CSCLIP re-implemented (Sec. 2.1; Suppl. A7).
- Best result: 36 datasets, 235 anatomies (Table 1, p. 11): CL-Net^U36 mean DSC 86.1 %, ASD 1.17 mm, 55.5 MB; CL-Net^C36 (continual) 85.7 %, 1.20 mm; nnU-Net ensemble 83.9 %, 1.32 mm, 1,126.8 MB. Five public datasets, mean (Table 2, p. 14): CL-Net^U5 92.9 % vs nnU-Net ensemble 92.5 %, MultiTalent 90.2 %, SAT-Pro 83.0 %. Continual CL-Net^C5, final mean DSC 92.6 % averaged over the four orders (92.6, 92.6, 92.7, 92.5 % for O1–O4) vs MiB 30.0 %, PLOP 46.0 %, CSCLIP 43.6 % (Sec. 2.3, p. 17; Suppl. A3, p. 44). BiomedParse in 3D on FLARE22: 23.7 % (Table 3). External: mean DSC CL-Net^U36 82.8 %, CL-Net^C36 82.4 %, nnU-Net ensemble 81.5 % (Table 4, p. 17, checked in the PDF). "Significantly" is used without a test for most main comparisons; p-values appear only in supplement ablations (e.g. p. 52 ff.).
- Limitations stated by the authors (Sec. 3, p. 21–22): no detailed brain anatomies and few lesion types; only a CNN encoder tested; LTH pruning does not reduce FLOPs; lymph node stations only for head & neck and chest.

## Check of the author's notes
- related_work.tex:83 "CL-Net extends the same design to 235 anatomical structures across 36 CT datasets" → correct (Abstract; Sec. 2; it extends Continual Segment, Sec. 1, p. 6); "same design" is accurate in outline (frozen general encoder, added decoders), but CL-Net switches from dataset-wise to organ-wise decoders and adds LTH pruning (Sec. 1, p. 6).
- related_work.tex:83 "Retention in these systems is close to complete, since earlier components are never updated" → partly correct for CL-Net: no forgetting is shown across four orders (Fig. 4), but existing decoders are updated by EMA fine-tuning when an anatomy reappears in a later dataset (Sec. 2, p. 8; Suppl. A2, p. 43). "Never updated" is wrong for CL-Net.
- related_work.tex:83 "the cost is that model size grows with the number of tasks" → correct, but the growth is small after pruning (mean decoder pruning rate 97.5 %, 55.5 MB for 235 anatomies; Sec. 2.2, p. 12).
- related_work.tex:83 "and that nothing learned for one task benefits the others" → wrong for CL-Net: the frozen general encoder is shared by all decoders, and feature-level supporting injects decoder features of adjacent organs into other decoders, e.g. +2.1 % DSC for lymph node stations (Sec. 2.2, p. 12).

Either change the result to "DSC 85.7 % (continual, 235 structures)" or the data cell to "5 public CT datasets, 137 structures".

## Relevance (NOT from the paper)
Strongest architectural-isolation example in medical segmentation: near-zero forgetting, task-identity-free inference and order robustness, but it relies on full datasets and a fixed label set without text prompts, unlike the few-shot free-text setting here.
