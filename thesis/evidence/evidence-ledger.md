## Reproducibility Checklist

- [ ] Dataset names, versions, splits, and case counts recorded
- [ ] Preprocessing and augmentation parameters recorded
- [ ] Model and checkpoint identifiers recorded
- [ ] Training and evaluation configurations linked
- [ ] Random seeds recorded
- [ ] Hardware and software environment recorded
- [ ] Runtime, memory consumption, and relevant computational complexity recorded
- [ ] Metrics and aggregation procedure defined
- [ ] Figures and tables linked to source data
