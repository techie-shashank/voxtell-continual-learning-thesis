Runs (role "Main" in `results/experiment_index.csv`, original order, full split): seq. Numbers: `cl_metrics.csv`, `cl_differences.csv`, `eval_matrix.csv` of each run. About 3 pages incl. Table `ch6_main`, Figs. `ch6_main_metrics`, `ch6_main_matrices`, `ch6_control_task_main`.

1. **Question and setup** (1 short paragraph): five strategies, full split, original order; reminder that the evaluated checkpoint differs (LoRA: last epoch; the others: best validation, 6.1.3).
2. **Two groups in the primary metrics** (Table, bar plot): seq. FT, distillation-based and prompt tuning reach the highest Adaptation (0.717, 0.744, 0.608) but forget almost all earlier tasks (Final Forgetting 0.704, 0.732, 0.568) and the control task (drop 0.979 for all three: lung DSC from 0.979 to ≤ 0.0004). The LoRA strategies adapt less (0.485, 0.471) and retain more (forgetting 0.000 by construction / 0.289; drop 0.000 / 0.237). Paired differences vs seq. FT with intervals.
3. **What the final model can do** (Final Performance, matrices): the three full-update strategies end at 0.130–0.135, barely above the pretrained model (0.114) — after six tasks they segment essentially only the last structure, and lose femoral cartilage, which the pretrained model segmented (0.684 → ≤ 0.006). Task-specific LoRA ends highest without replay (0.485), shared LoRA 0.233.
4. **Distillation-based vs seq. FT**: distillation did not reduce forgetting in this run (0.732 vs 0.704; drop identical). Negative result, stated plainly; λ = 0.01 untuned (5.4.4).
5. **Prompt tuning**: all pretrained weights frozen, yet forgetting 0.568 and control-task drop 0.979. Fact only here; explanation per Q3.
6. **Transfer** (secondary): LoRA strategies 0.129/0.174 ≈ pretrained 0.137; full-update strategies 0.001–0.043, i.e. before training a task they segment none of it.
7. **Control-task curve** (Fig.): lung lost already after the first task for the full-update strategies (0.002, 0.108 prompt tuning), shared LoRA stays ≥ 0.955 until the last task (link to 6.6).
8. **Replay** (per Q4).
9. **Conclusion** (author, Q1–Q2).
